# DuoFollow

[English version](README.en.md)

DuoFollow сравнивает подписки и подписчиков аккаунта Duolingo и показывает невзаимные подписки.

Для работы нужен Chrome или Microsoft Edge на компьютере и расширение **DuoFollow Connector**. [Как установить расширение из проекта](docs/guidelines/development-guidelines.md#запуск-локально).

Microsoft Edge использует ту же сборку расширения. Установка и проверки описаны в [плане совместимости](docs/guidelines/browser-device-compatibility.md#проверка-microsoft-edge).

Экспериментальная сборка Firefox и порядок проверки описаны в [инструкции Firefox](docs/guidelines/firefox.md).

## Как пользоваться

1. Для работы нужна активная сессия Duolingo в том же профиле браузера, где открыт [DuoFollow](https://hedgerock.github.io/duofollow/).
2. Пункт **«Управлять доступом к Duolingo»** открывает описание используемых данных и ссылку на настройки Connector. Кнопка **«Разрешить доступ»** в настройках включает доступ.
3. После возврата на сайт DuoFollow определяет открытый аккаунт и начинает сравнение. Кнопка **«Обновить сравнение»** обновляет результат. Если аккаунт не удалось определить, в форме можно указать его имя.
4. Переключатель задаёт вид списка, а поиск находит профили по имени или `@username`. Рядом с поиском доступна сортировка. Стрелка в карточке открывает профиль в Duolingo.
5. Кнопка с человечком и минусом запускает отписку от невзаимного профиля. Диалог на сайте показывает выбранный профиль. При включённой «Быстрой отписке» подтверждения в этом диалоге достаточно. В стандартном режиме расширение запрашивает дополнительное подтверждение.

Карточки результатов показывают, сколько подписок и подписчиков удалось проверить. Метка **«Частично»** раскрывает пояснение к неполному списку. Счётчик справа от заголовка списка показывает число профилей в выбранном виде, а при поиске — число совпадений из общего числа в этом списке.

В общем списке цветные полоски отмечают статус профиля. Если список подписчиков загружен частично, фильтр «Невзаимные» недоступен. Пояснение видно под переключателем. В шапке есть ссылка на профиль, для которого показан результат.

При отключённом расширении или отсутствии сессии Duolingo подсказка показывает шаги для восстановления подключения. Кнопка **«Проверить снова»** обновляет статус.

Замок в шапке DuoFollow открывает страницу управления доступом со ссылкой на настройки Connector. Кнопка **«Отключить доступ»** в настройках отзывает разрешения. Настройки также открываются через значок расширения.
В шапке можно сменить язык сайта и тему. Язык расширения выбирается отдельно на его странице настроек. В **«Настройках»** можно увеличить текст, выбрать шрифт, включить узоры для различения статусов подписок и отключить всплывающие подсказки.
