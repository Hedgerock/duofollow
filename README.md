# DuoFollow

DuoFollow показывает, кто из тех, на кого ты подписан в Duolingo, не подписан на тебя в ответ.

Для работы нужен Chrome на компьютере и расширение **DuoFollow Connector**. [Инструкция по первому запуску](docs/guidelines/development-guidelines.md#запуск-локально).

## Как пользоваться

1. Войди в Duolingo и открой DuoFollow в том же профиле Chrome.
2. Введи своё имя пользователя и нажми **«Сравнить мои подписки»**.
3. Найди человека по имени или `@username`. Стрелка в карточке открывает его профиль в Duolingo.
4. Нажми кнопку с человечком и минусом, затем подтверди отписку в открывшемся окне.

Над списком видно, сколько подписок удалось проверить из общего числа. В шапке есть ссылка на профиль, для которого показан результат.
