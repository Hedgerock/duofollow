# DuoFollow

[Read in English](README.en.md)

DuoFollow показывает, кто из тех, на кого ты подписан в Duolingo, не подписан на тебя в ответ.

Для работы нужен Chrome на компьютере и расширение **DuoFollow Connector**. [Как установить расширение из проекта](docs/guidelines/development-guidelines.md#запуск-локально).

## Как пользоваться

1. Войди в Duolingo и открой [DuoFollow](https://hedgerock.github.io/duofollow/) в том же профиле Chrome.
2. При первом открытии выбери **«Управлять доступом к Duolingo»**. Прочитай, какие данные используются, затем открой настройки Connector и нажми **«Разрешить доступ»**.
3. Вернись на сайт, введи имя открытого аккаунта и нажми **«Сравнить мои подписки»**.
4. Выбери вид списка и найди профиль по имени или `@username`. Сортировку можно изменить рядом с поиском. Стрелка в карточке открывает профиль в Duolingo.
5. Для невзаимной подписки нажми кнопку с человечком и минусом и подтверди отписку.

Карточки результатов показывают, сколько подписок и подписчиков удалось проверить. Счётчик справа от заголовка списка показывает число профилей в выбранном виде, а при поиске — число совпадений из общего числа в этом списке.

В общем списке цветные полоски отмечают статус профиля. Если список подписчиков загружен частично, фильтр «Невзаимные» недоступен. Пояснение видно под переключателем. В шапке есть ссылка на профиль, для которого показан результат.

Если сайт просит включить расширение или войти в Duolingo, выполни шаги из подсказки и нажми **«Проверить снова»**.

Чтобы отозвать доступ, нажми на замок в шапке DuoFollow, открой настройки Connector и выбери **«Отключить доступ»**. Настройки также открываются через значок расширения.
В шапке можно сменить язык и тему. В **«Настройках»** можно увеличить текст, выбрать шрифт и включить узоры для различения статусов подписок.
