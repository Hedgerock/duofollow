# Проверка выделения core и браузерных адаптеров

## Область

Дата: 22 ноября 2026 года. Базовый commit — `18936cf`.
Изменение реализует [ADR-0016](../decisions/records/0016-browser-core-and-adapters.md).
Chrome и Edge сохраняют одну сборку, прежние маршруты API, ключи хранилища и версии согласия.
Firefox-сборка и content script в эту проверку не входят.

Общие сценарии находятся в `extension/src/core`; вызовы браузерного SDK — в Chromium-адаптере.
Вход worker связывает их при запуске. Клиент сайта принимает объект транспорта и продолжает проверять неизвестные ответы.

## Автоматические результаты

304 unit-теста прошли. Новые 30 проверок включают 18 случаев общего контракта платформы,
10 случаев транспорта и 2 проверки архитектурных границ.
Один и тот же core проверен против платформы в памяти и настоящего Chromium-адаптера над подставным SDK.
Проверки выполняются без глобального `chrome`.

57 интеграционных сценариев Chromium прошли с двумя воркерами, включая установленный тестовый Connector,
стандартную и быструю отписку, отмену, восстановление после потери ответа, навигацию, настройки и подсказки.
Ответы Duolingo подставлены. Записи в реальные аккаунты не выполнялись.

Штатные команды `npm run build` и `npm --prefix extension run build` прошли после итоговой проверки.
Собранный сайт соответствует проверенному интеграционными сценариями bundle.
Страницы выдавались из готового `dist` маршрутизацией Playwright из-за ограничений локального HTTP-сервера.

## Оставшиеся проверки среды

Запуск установленного Edge завершился до открытия страницы: процесс закрылся с ошибкой канала Crashpad.
Результат не подтверждает прохождение актуального набора Edge. Команда `npm run test:edge`
и Windows-задание CI остаются проверкой этого окружения.

Docker Engine в окружении ревизии недоступен из-за отказа доступа к именованному каналу.
Linux-скриншоты и контейнерный прогон текущей реализации не выполнены.
Успешный Docker-отчёт предыдущей итерации относится к исходному состоянию до выделения core.

После применения изменения выполняются сборки, `npm run test:browser:docker` и `npm run test:edge`.
Распакованное расширение перезагружается в Chrome и Edge. Ручная проверка охватывает реальную сессию,
выдачу и отзыв доступа, сравнение, стандартную и быструю отписку, окно подтверждения и размещение настроек.
