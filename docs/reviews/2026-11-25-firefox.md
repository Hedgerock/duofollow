# Проверка Firefox от 25 ноября 2026 года

## Область

Итерация добавляет Firefox-сборку, нативный адаптер и канал через content script поверх core из ADR-0016.
Страницы расширения используют адаптер, выбранный сборкой. Исторические ADR не изменены.
[ADR-0017](../decisions/records/0017-firefox-bridge-and-build.md) · [Инструкция](../guidelines/firefox.md)

## Проверено

- Vitest: 332 теста в 18 файлах. Общий контракт содержит девять сценариев для платформы в памяти,
  Chromium- и Firefox-адаптеров. Дополнительные случаи проверяют источник порта, документ,
  отмену, ограничение очереди, подписки и актуальное положение вкладки.
- Chromium: 57 существующих интеграционных тестов прошли. Проверка отсутствующего content script и новый сквозной сценарий Firefox-канала
  прошли после исправления тестового ответа активного профиля по ID. Используются настоящие события
  Window, код транспорта, content script, адаптера и core; SDK и ответы Duolingo заменены.
  Локальные страницы предоставлялись из сборки через маршрутизацию Playwright.
- TypeScript, ESLint, Prettier, сборка сайта и обе сборки расширения входят в локальную проверку.
- web-ext lint: 0 ошибок, предупреждений и notices. Сообщение о недоступном локальном кеше
  проверки обновлений web-ext не относится к результату проверки расширения.
- Production ZIP Firefox создаётся отдельно. Manifest архива содержит background.scripts,
  только production origin DuoFollow и необязательные разрешения Duolingo; localhost отсутствует.

## Ограничения запуска

Окружение: Windows NT 10.0.26200.0, Node 22.18.0, Playwright 1.57.0.
Firefox 144.0.2 из Playwright завершился до открытия страницы с кодом 3221225477 (0xC0000005).
Проверка с отдельным профилем вне временного каталога дала тот же результат.
web-ext не смог подключиться к процессу через RDP. Это не является успешным прогоном установленного расширения.

Проект test:firefox и сценарий test:firefox:extension добавлены в отдельное задание CI.
Их успешное выполнение в Firefox в текущем окружении не подтверждено. Edge и Docker заново не запускались;
проверки общего Chromium-адаптера входят в Vitest и Chromium-набор.

## Условия приёмки

Требуются успешные test:firefox и test:firefox:extension в рабочем окружении Firefox.
Ручной прогон проверяет текущую реальную сессию, выдачу и отзыв разрешения, смену аккаунта,
стандартную и быструю отписку, перенос вкладки и вёрстку по списку из инструкции.
Реальные аккаунты и запросы DELETE к Duolingo автоматическими проверками не используются.
Публикация, подпись и окончательные декларации AMO оформляются отдельно.

## Контрольный прогон и исправления совместимости

Разработчик подтвердил успешное выполнение сценария установленного Firefox-расширения:
cookie и согласие, сравнение, настройки, быстрое подтверждение, чтение результата и изоляция после перезагрузки.
После вывода результата библиотека firefox-profile получила EBUSY при удалении favicons.sqlite.
Версия браузера в сообщении не указана. Прогон использовал тестовые ответы Duolingo и не подтверждает реальную сессию.

Трассы семи интерфейсных падений показали немедленное скрытие закрытого диалога в Firefox,
неподходящий способ задания клавиатурного фокуса и отсутствие подтверждённого открытия native select.
Заголовок и счётчик прошли проверки геометрии; соответствующий тест завершался на ожидании подсказки имени.

Диалог сохраняет open до окончания собственных переходов; закрытие, повторное открытие,
размонтирование и уменьшение движения покрыты отдельными тестами.
Тесты подсказок используют Tab и настоящий picker из showPicker() в доверенном событии.
В проверенном Chromium-наборе первый Escape закрывает picker, следующий закрывает восстановленную подсказку.
Native-тест использует собственный профиль, ждёт registerCleanup и повторяет удаление при временных блокировках.

Локально проходят 341 модульный тест и 59 интеграционных тестов Chromium со статической раздачей сборки через Playwright.
Повторный Firefox-прогон и фактическая очистка профиля требуют проверки
в окружении разработчика: Firefox в среде агента по-прежнему завершается до открытия страницы с 0xC0000005.

## Повторная проверка подсказок

Разработчик подтвердил успешный native-прогон после исправления очистки профиля, без прежнего предупреждения EBUSY.
Остались четыре интерфейсных случая. Трассы показывают отсутствие open после открытия picker указателем,
потерю подсказки после клавиатурного Escape и уход фокуса при обратном Tab с первой ссылки страницы.

Монитор picker сохраняет исходное клавиатурное намерение через временный blur и проверяет фактический
activeElement при закрытии. Если нативное меню закрылось до возврата фокуса окну, восстановление ждёт
события focus без постоянного опроса. Наблюдение повторно запускается на click. Обработчик Escape не
закрывает подсказку одновременно с нативным picker. Клавиатурный тест дожидается прокрутки после установки
фокуса и возвращается через Tab. Для первой ссылки направление переходов меняется, чтобы не перейти
назад в панель браузера. Переход ограничен числом шагов и завершается строгой проверкой фокуса.
Артефакт сбоя select содержит состояние open, видимость документа и последовательность открытия.

Добавлены семь модульных регрессий: временный blur без focus-visible, два последовательных Escape,
открытие на click, перенос фокуса на другой элемент, скрытый документ, отложенный возврат фокуса окну
и удаление ожидающего обработчика при размонтировании. Локально проходят 348 модульных тестов и
59 интеграционных проверок Chromium со статической раздачей сборки через Playwright.
Локальный Firefox-набор ограничен одним worker, как CI, чтобы проверки нативных меню и фокуса
выполнялись последовательно. Повторное выполнение в Firefox остаётся условием приёмки.

## Граница автоматизации нативного меню

После повторного прогона остались три сценария select; проверка шапки больше не входит в список падений.
JSON-вложения показывают :open = true после showPicker(), Escape и Enter, при сохранённом фокусе
select и документа. Ожидание восстановления подсказки ещё не достигло закрытого меню.

В Playwright 1.57 Firefox отправляет клавиши через
[PageAgent](https://github.com/microsoft/playwright/blob/v1.57.0/browser_patches/firefox/juggler/content/PageAgent.js#L436-L460)
в content-процесс, тогда как
[SelectChild](https://github.com/mozilla/gecko-dev/blob/master/toolkit/actors/SelectChild.sys.mjs)
открывает список в родительском процессе. Наблюдение согласуется с
[ограничением нативного select](https://github.com/microsoft/playwright/issues/28860), указанным командой Playwright.
Предположение, что исправления DOM-фокуса достаточно для этих трёх тестов, не подтвердилось.

Три проверки нативных клавиш явно пропускаются только для Firefox с причиной и ссылкой на ограничение.
Chromium сохраняет эти проверки. Два новых общих сценария открывают настоящее меню, дожидаются исчезновения
прежней подсказки, закрывают меню через blur и строго проверяют :open = false. Первый сохраняет указатель
на месте, второй возвращает фокус до завершения закрытия и проверяет Escape на восстановленной подсказке.
Состояние меню, CSS-псевдоклассы и методы браузера не подменяются. Сортировка уже проверяется через
selectOption() и фактический порядок профилей.

Ручная приёмка Firefox отдельно фиксирует отмену, выбор пункта и два последовательных Escape.
Пропуск нативных клавиш в автоматическом наборе не подтверждает эти три сценария.

После изменения проходят 348 модульных тестов и 61 интеграционная проверка Chromium со статической
раздачей сборки через Playwright. Два новых сценария также прошли три последовательных повтора.
Firefox собирает 60 сценариев; три проверки нативных клавиш имеют явную причину пропуска.
Сбор тестов не является их выполнением: успешный Firefox-прогон и ручная приёмка остаются неподтверждёнными
в среде агента. Прикладной код и исторические ADR в этом исправлении не изменены.

## Ручная проверка от 26 ноября 2026 года

Разработчик подтвердил выполнение предложенного ручного прогона в установленном Firefox.
Дефектов не обнаружено; сценарии с клавиатурой без использования указателя выполнили ожидаемое поведение.

| Параметр            | Значение                                         |
| ------------------- | ------------------------------------------------ |
| Дата                | 26 ноября 2026 года                              |
| ОС                  | Windows 11                                       |
| Браузер             | Firefox 161.0                                    |
| Источник результата | Подтверждение разработчика после ручной проверки |

Точный commit, размер окна, масштаб текста и канал выпуска Firefox в сообщении не указаны.

Подтверждены действия из предложенного порядка проверки:

- Подключение установленной Firefox-сборки, определение аккаунта и сравнение подписок.
- Возврат из политики конфиденциальности к сравнению без обнаруженных нарушений соединения или результата.
- Закрытие нативной сортировки через Escape без перемещения указателя: подсказка восстанавливается,
  выбранная сортировка сохраняется.
- Выбор другого пункта через стрелку и Enter: сортировка меняется, подсказка восстанавливается.
- Переход через Tab, открытие меню пробелом и два последовательных Escape без мыши:
  первый закрывает меню и возвращает подсказку, второй скрывает подсказку.

Эти ручные результаты дополняют три явно пропущенных автоматических проверки нативных клавиш.
Пропуски сохраняются в Playwright и не считаются автоматическим покрытием.
Результат относится к Firefox 161.0 на Windows 11 и не заменяет расширенную матрицу разрешений,
смены сессии, операций записи и отображения на других конфигурациях. Публикация и подпись AMO
остаются отдельными условиями выпуска. Исторические ADR не изменены.
