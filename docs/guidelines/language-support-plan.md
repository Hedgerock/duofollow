# План локализации и выбора языка

## Текущее состояние

Сайт и расширение поддерживают `en`, `ru` и `uk`. Сайт сохраняет язык в `duofollow.language`,
а расширение хранит отдельное предпочтение. Материал описывает будущие изменения словарей и переключателя.

## Очередность языков

| Порядок | Язык      | Код  | Название в списке | Направление |
| ------- | --------- | ---- | ----------------- | ----------- |
| 1       | Испанский | `es` | Español           | `ltr`       |
| 2       | Шведский  | `sv` | Svenska           | `ltr`       |
| 3       | Арабский  | `ar` | العربية           | `rtl`       |

Арабский выбран первым языком для проверки письма справа налево. Каждый язык выпускается отдельной итерацией
со словарями сайта и расширения, локализованными доступными названиями и политикой конфиденциальности.
Маршруты переводов политики проходят проверку прямого открытия на GitHub Pages и возврата к сравнению.

## Описание языка

Планируется общий каталог метаданных для интерфейса сайта и расширения.
Словари текстов и сохранённые предпочтения остаются в своих областях хранения.

| Поле              | Назначение                                                                                                        |
| ----------------- | ----------------------------------------------------------------------------------------------------------------- |
| `code`            | Тег языка BCP 47. Значения `en`, `ru`, `uk`, `es`, `sv`, `ar` используются при сохранении выбора и поиске словаря |
| `nativeName`      | Название на собственном языке для открытого списка                                                                |
| `direction`       | Значение `ltr` или `rtl` для страницы                                                                             |
| `flagCountryCode` | Необязательный код страны ISO 3166-1 alpha-2 для поиска названия страны и локального изображения флага            |

Код языка и код страны имеют отдельные поля. У одного языка могут быть разные региональные варианты.
Код страны задаёт изображение в интерфейсе. Настройки языка, форматирования и направления берутся из
тега языка и его метаданных. [Языковые теги BCP 47](https://www.w3.org/International/articles/language-tags/index.en).

Для иллюстрации каталога шведский может иметь `code: 'sv'` и `flagCountryCode: 'SE'`, испанский —
`code: 'es'` и `flagCountryCode: 'ES'`. Русский `ru` и арабский `ar` используют `flagCountryCode: null`
и нейтральную иконку глобуса. Компактная кнопка различает эти языки по коду, а подсказка и открытый список
показывают полное название. Отображаемый флаг обозначает выбранную иллюстрацию языка и может уточняться
в ходе реализации переключателя.

Код страны позволяет в дальнейшем получить название через `Intl.DisplayNames` или локальный каталог.
Явный выбор страны проживания относится к самостоятельной функции с собственным полем данных.
Каталог загружается из сборки. Флаги используют локальные ресурсы и поддерживают нейтральную замену при отсутствии изображения.

## Переключатель языка

Предпочтительный компактный вариант кнопки содержит флаг или глобус и код текущего языка.
Код сохраняет узнаваемость при отсутствии изображения. Раскрытый список содержит флаг при его наличии,
название языка на собственном языке и отметку выбранного варианта. В настройках и на странице доступа
полное название видно непосредственно в списке.

Подсказка показывает полное название языка при наведении или фокусе с клавиатуры. Появление и исчезновение
плавные, с учётом уменьшения движения. Подсказка помещается в видимой области, остаётся читаемой при движении
указателя к ней и закрывается по Escape. Оформление согласуется с подсказками отписки и статуса взаимности.
[Содержимое при наведении и фокусе](https://www.w3.org/WAI/WCAG21/Understanding/content-on-hover-or-focus.html).

При касании кнопка открывает список с полными названиями. Доступное название элемента сообщает выбор языка
и текущий вариант. Флаг имеет декоративную роль, а название пункта доступно скринридеру.
Ввод с клавиатуры охватывает открытие списка, перемещение по вариантам, подтверждение, Escape
и возврат фокуса на кнопку. Смена языка требует явного выбора пункта.

Дизайн проверяется в шапке, диалоге подключения, настройках расширения и окне подтверждения отписки.
Реализация выбирает доступный элемент управления с учётом возможностей Chrome, Edge и Firefox.
Итоговый подход и совместимость прежних сохранённых кодов фиксируются в ADR реализации.

## Поддержка RTL

При выборе арабского корневой элемент получает `lang="ar"` и `dir="rtl"`.
При возврате к другим языкам восстанавливается `dir="ltr"`. Для отступов и выравнивания используются
логические свойства CSS. [Направление документа](https://www.w3.org/International/questions/qa-html-dir).

Проверка включает общий макет, шапку, счётчики, панели, диалоги, уведомления, раскрывающийся список,
подсказки и политику. Направление имён определяется по содержимому. Username, URL и технические ID
изолируются от окружающего арабского текста. Пунктуация, смешанные строки и копирование проверяются
на тех же тестовых профилях.

Навигационные стрелки проверяются по смыслу действия в RTL. Логотип, аватары и независимые от направления
пиктограммы сохраняют свою ориентацию. Поиск, сортировка и форматирование чисел следуют выбранной локали.
Статус взаимности остаётся различимым по текстовому доступному названию и узору.

## Приёмка языковой итерации

- Переведены видимые подписи, сообщения об ошибках, доступные названия и публичная политика.
- Фиксируется полнота словаря и переход на английский при отсутствующем переводе.
- Региональные настройки браузера сопоставляются с поддерживаемым кодом языка.
- Переключение и перезагрузка сохраняют выбор, текущий результат сравнения и доступность интерфейса.
- При навигации между политикой, доступом и главной сохраняются действующие правила выбора языка маршрута.
- Проверены 320 CSS px, промежуточная ширина 796 CSS px, широкий экран, все размеры текста, шрифты и оба цветовых режима.
- Проверены открытый список, подсказки, фокус, Escape, касание и отсутствие изображения флага.
- Для арабского проверены RTL, смешанные имена, направление ввода и восстановление LTR.
- Новый язык проходит проверку текста человеком, владеющим этим языком, до публичного выпуска.

## Возможное расширение языковых проверок

Рассматривается отдельная итерация автоматической проверки качества переводов.
Область включает словари сайта, сообщения расширения и текст публичной политики.
Кандидат для грамматики, орфографии и пунктуации — LanguageTool.
При оценке инструмента проверяется качество правил для каждого поддерживаемого языка и коротких подписей интерфейса.
[Перечень языков LanguageTool](https://dev.languagetool.org/languages)

Предполагаемые проверки охватывают следующие случаи.

| Проверка                | Ожидаемый результат                                                                       |
| ----------------------- | ----------------------------------------------------------------------------------------- |
| Полнота словарей        | Выявлены отсутствующие ключи и пустые переводы                                            |
| Подстановки             | Сохранены имена, числа, ссылки и параметры сообщений                                      |
| Грамматика и орфография | Сформированы замечания с языком, ключом строки и идентификатором правила                  |
| Формы числительных      | Проверены результаты шаблонов для 0, 1, 2, 5, 11, 21 и 101                                |
| Терминология            | Проверено употребление утверждённых переводов подписок, подписчиков, взаимности и отписки |

Первый этап формирует отчёт. Разбор замечаний выделяет реальные ошибки и исключения с обоснованием.
Обязательные правила CI выбираются после оценки стабильности проверки.
Ошибки структуры словаря и потерянные подстановки могут стать причиной падения тестов,
а грамматические замечания первоначально показываются как рекомендации.
Контекстный смысл перевода и короткие команды проходят языковое ревью.

Для автоматического запуска рассматривается собственный экземпляр LanguageTool с закреплённой версией
или тариф, допускающий автоматизацию. Автоматические запросы к публичному бесплатному API запрещены условиями сервиса.
Проверка получает подготовленные строки переводов. В отчёт входят версия инструмента и выбранные правила.
[Локальный сервер](https://dev.languagetool.org/http-server),
[условия публичного API](https://dev.languagetool.org/public-http-api.html).

Выбор инструмента, формат отчёта и правила CI фиксируются в ADR при реализации этого расширения.
