# ADR-0002: Браузерные проверки pull request

## Статус

Accepted

---

## Контекст

Интеграционные тесты и сверка скриншотов запускаются локально. Pull request может пройти без браузерной проверки.
Эталоны хранятся в репозитории и зависят от версии Chromium и окружения отрисовки.

---

## Решение

GitHub Actions запускает браузерную проверку для pull request. Проверка использует команду
`npm run test:browser:docker` и образ Playwright из `compose.test.yml` на Linux AMD64.
Playwright выполняет интеграционные и скриншотные тесты последовательно. Тесты подставляют ответы Connector.
При сбое GitHub Actions сохраняет доступные трассировки и снимки из `test-results`.

---

## Последствия

Локальный запуск через Docker и проверка pull request используют одно окружение. Изменения интерфейса сверяются
с Linux-эталонами из репозитория. Обновление эталонов входит в изменение интерфейса после просмотра новых снимков.

---

## Границы решения

Проверка pull request и публикация GitHub Pages работают в отдельных workflow. Нагрузочный тест запускается отдельной
командой.
