# ADR-0012: Поддержка Microsoft Edge

## Статус

Accepted

---

## Контекст

Connector использует Manifest V3 и Chromium API. Microsoft Edge поддерживает этот формат,
но отдельная установка может получить другой ID. Сайт использовал один ID и показывал инструкции Chrome.
Проверки интерфейса выполнялись в Chromium из Playwright и не подтверждали отображение в установленном Edge.

---

## Решение

Chrome и Edge используют одну сборку расширения. Разрешения, список отправителей и протокол команд сохраняются.
Сайт получает сведения об Edge из Client Hints или настольного токена `Edg/`. Эти сведения выбирают инструкции
и ID расширения. Проверка доступности по-прежнему выполняется через Runtime API и ответы Connector.

Для Edge используется необязательная переменная `VITE_DUOFOLLOW_EDGE_EXTENSION_ID`.
При её отсутствии применяется `VITE_DUOFOLLOW_EXTENSION_ID`, что позволяет использовать общий ID распакованной сборки.
Рабочая область и страница доступа получают ID через одну функцию. Переменные задаются при сборке сайта.

Команда `npm run test:edge` запускает интеграционные проверки интерфейса в канале `msedge`.
Отдельное задание CI выполняется на Windows. Проверки установленного тестового расширения остаются в Chromium:
Playwright не поддерживает прежнюю загрузку расширений через командную строку в брендированном Edge.

---

## Последствия

Для разных ID Chrome и Edge достаточно конфигурации сборки сайта. Дополнительные разрешения не требуются.
Подсказки на трёх языках показывают страницу расширений текущего браузера. Настройки расширения описывают общий профиль браузера.
Linux-эталоны Chromium сохраняются; Edge проверяет поведение и геометрию элементов без заимствования чужих PNG-эталонов.

---

## Границы решения

Автоматические проверки Edge используют смоделированный канал Connector. Они подтверждают выбор ID, навигацию,
состояния и геометрию интерфейса. Поддержка реальной сессии, выдача и отзыв разрешений, подтверждённая отписка
и распространение через Microsoft Edge Add-ons требуют отдельной ручной проверки и подготовки выпуска.
Критерии и журнал проверки находятся в плане совместимости.

Firefox, мобильные браузеры и другие сочетания ОС с браузером остаются отдельными итерациями.
