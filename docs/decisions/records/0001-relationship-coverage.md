# ADR-0001: Охват списков Following и Followers

## Статус

Accepted

---

## Контекст

Connector получает списки Following и Followers для сравнения по идентификаторам профилей.
На момент принятия решения контрольный замер с `pageSize=500` дал следующие результаты.

| Список    | Страница | Отправленный курсор | Следующий курсор | Уникальных ID на странице | Новых ID | Итог Duolingo |
| --------- | -------: | ------------------- | ---------------- | ------------------------: | -------: | ------------: |
| Following |        1 | `null`              | `v1:500`         |                       376 |      376 |           695 |
| Following |        2 | `v1:500`            | `v1:500`         |                       376 |        0 |           695 |
| Followers |        1 | `null`              | `null`           |                       130 |      130 |           130 |

Курсор Following в этом замере повторил набор ID. Первая страница Followers покрыла весь объявленный список.

---

## Решение

Connector обрабатывает первую страницу каждого списка и вычисляет охват по уникальным ID.
Полный охват подтверждают конечный курсор `null` и совпадение числа уникальных ID с `totalUsers`.
При частичном охвате Connector передаёт его причину, а сайт показывает пояснение рядом со счётчиком.

---

## Последствия

Сравнение охватывает профили, полученные на первой странице. При частичном Followers статусы профилей,
отсутствующих среди полученных подписчиков, остаются неопределёнными. Старые версии Connector передают
счётчики в прежнем формате.

---

## Границы решения

Автоматическая загрузка следующих страниц относится к отдельному решению после подтверждения перехода
с новыми ID для соответствующего маршрута.
