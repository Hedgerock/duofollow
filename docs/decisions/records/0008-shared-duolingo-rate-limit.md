# ADR-0008: Общая пауза запросов Duolingo после HTTP 429

## Статус

Accepted

---

## Контекст

Ответы Duolingo с HTTP 429 сохраняют срок паузы в сессионном хранилище расширения.
Этот срок учитывает проверка входа. Сравнение и отписка могут отправлять новые запросы
в тот же период из другой вкладки или по ранее открытому диалогу.

---

## Решение

Фоновый процесс применяет один срок ожидания ко всем запросам Connector к API Duolingo.
При HTTP 429 срок определяется по `Retry-After`. При отсутствии корректного значения пауза
составляет 60 секунд. Из нескольких ответов сохраняется самый поздний срок.
Запись в `chrome.storage.session` сохраняется при перезапуске фонового процесса.

Перед новым запросом Connector проверяет срок, включая повторный поиск профиля и финальный
`DELETE` после подтверждения отписки. В период паузы проверка сессии, сравнение и попытка
отписки сообщают `RATE_LIMITED`. Уже отправленные запросы завершаются по действующим правилам.

---

## Последствия

Запросы из разных вкладок используют одну паузу. По истечении срока следующий запрос может
выполниться. Для новой попытки отписки требуется новое подтверждение. Если чтение Following
для проверки уже отправленной отписки блокируется паузой, исход остаётся неизвестным.

---

## Границы решения

Пауза распространяется на HTTP-запросы Connector к API Duolingo. Сайт загружает изображения
самостоятельно. Автоматическое повторение запросов отписки отсутствует.
