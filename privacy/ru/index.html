Политика конфиденциальности

Обновлено 15 ноября 2026 года

Политика распространяется на сайт DuoFollow и расширение DuoFollow Connector для Chrome. DuoFollow — независимый проект, который поддерживает Dmitro Vasyliev.

Данные для работы с Duolingo

После выдачи доступа в настройках Connector расширение читает cookie сессии на www.duolingo.com, чтобы определить активный аккаунт и проверить вход. Значение cookie используется внутри расширения и браузером для авторизованных запросов к Duolingo. Страница DuoFollow получает статус подключения.

Для сравнения Connector отправляет введённое имя пользователя в Duolingo. Из ответа он использует ID аккаунтов, имена пользователей, отображаемые имена, ссылки на аватары и сведения о подписках. Сравнение выполняется в браузере. Connector передаёт результаты и нужные для их отображения сведения о профилях странице DuoFollow. После подтверждения отписки расширение отправляет Duolingo ID аккаунта и выбранного профиля, чтобы удалить подписку. При потере ответа Connector может перечитать список подписок, чтобы проверить результат.

Куда передаются данные

У DuoFollow нет сервера разработчика с базой аккаунтов или результатов. Duolingo получает HTTPS-запросы, необходимые для выбранных действий. Браузер загружает аватары напрямую с разрешённых серверов изображений по ссылкам из ответов Duolingo. Эти серверы получают сетевые данные, например IP-адрес.

Сайт DuoFollow размещён на GitHub Pages. GitHub регистрирует IP-адреса посетителей для безопасности. DuoFollow использует описанные данные только для своих функций. Данные не продаются и не используются для рекламы или решений о кредитоспособности. Обработка данных соответствует правилам Chrome Web Store о пользовательских данных, включая требования Limited Use.

Хранение и управление доступом

Connector хранит согласие и язык интерфейса в локальном хранилище расширения. Сайт сохраняет в браузере язык, тему, настройки оформления и имя аккаунта из последнего успешного сравнения. При следующем посещении и доступном подключении DuoFollow может повторить сравнение. Результаты хранятся в памяти страницы, а изображения может сохранять кэш браузера.

Сессионное хранилище Chrome содержит последнюю подтверждённую попытку отписки для проверки результата после перезапуска фонового процесса. В записи хранятся ID аккаунта и выбранного профиля и необратимое контрольное значение для сверки сессии, уникальное для запроса. После обработки исхода эти данные заменяются результатом. Сессионное хранилище очищается при перезапуске браузера.

Кнопка «Отключить доступ» в DuoFollow Connector отзывает разрешения. Сайт очищает результаты и сохранённое имя, когда получает сведения об отзыве. Доступ также можно отозвать в настройках Chrome. Очистка данных сайта DuoFollow в Chrome удаляет язык, тему, настройки оформления и сохранённое имя. Уже выполненные изменения подписок сохраняются в Duolingo.

Условия быстрой отписки

Быстрая отписка необязательна и выключена по умолчанию. При её включении кнопка «Отписаться» в диалоге на сайте DuoFollow подтверждает удаление выбранной подписки без открытия окна расширения.

Расширение хранит настройку локально. Сайт DuoFollow читает, включена ли она, чтобы выбрать порядок подтверждения. Отключение настройки возвращает дополнительное подтверждение в расширении.
