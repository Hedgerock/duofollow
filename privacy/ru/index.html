Политика конфиденциальности

Обновлено 15 ноября 2026 года

Политика распространяется на сайт DuoFollow и расширение DuoFollow Connector для Chrome. DuoFollow — независимый проект, который поддерживает Dmitro Vasyliev.

Данные для работы с Duolingo

После выдачи доступа в настройках Connector расширение читает cookie сессии на www.duolingo.com, чтобы определить активный аккаунт и проверить вход. Значение cookie используется внутри расширения и браузером для авторизованных запросов к Duolingo. Страница DuoFollow получает статус подключения.

Для сравнения Connector отправляет введённое имя пользователя в Duolingo. Из ответа он использует ID аккаунтов, имена пользователей, отображаемые имена, ссылки на аватары и сведения о подписках. Сравнение выполняется в браузере. Connector передаёт результаты и нужные для их отображения сведения о профилях странице DuoFollow. После подтверждения отписки Connector отправляет Duolingo ID аккаунта и выбранного профиля, чтобы удалить подписку.

Куда передаются данные

У DuoFollow нет сервера разработчика с базой аккаунтов или результатов. Duolingo получает HTTPS-запросы, необходимые для выбранных действий. Браузер загружает аватары напрямую с серверов изображений по ссылкам из ответов Duolingo. Эти серверы получают сетевые данные, например IP-адрес.

Сайт DuoFollow размещён на GitHub Pages. GitHub регистрирует IP-адреса посетителей для безопасности. DuoFollow использует описанные данные только для своих функций. Мы не продаём эти данные и не используем их для рекламы или решений о кредитоспособности. Мы соблюдаем правила Chrome Web Store о пользовательских данных, включая требования Limited Use.

Хранение и управление доступом

Connector хранит согласие в локальном хранилище расширения. Сайт сохраняет в браузере язык, тему и имя аккаунта из последнего успешного сравнения. При следующем посещении и доступном подключении DuoFollow может повторить сравнение. Результаты хранятся в памяти страницы, а изображения может сохранять кэш браузера.

Чтобы прекратить доступ, открой DuoFollow Connector и нажми «Отключить доступ». Connector отзывает разрешения, а сайт очищает результаты и сохранённое имя, когда получает сведения об отзыве. Доступ также можно отозвать в настройках Chrome. Чтобы удалить язык, тему и сохранённое имя, очисти данные сайта DuoFollow в Chrome. Уже выполненные изменения подписок сохраняются в Duolingo.
