Політика конфіденційності

Оновлено 15 листопада 2026 року

Політика поширюється на вебсайт DuoFollow і розширення DuoFollow Connector для Chrome. DuoFollow — незалежний проєкт, який підтримує Dmitro Vasyliev.

Дані для роботи з Duolingo

Після надання доступу в налаштуваннях Connector розширення читає файл cookie сеансу на www.duolingo.com, щоб визначити активний акаунт і перевірити вхід. Значення cookie використовується в розширенні та браузером для автентифікованих запитів до Duolingo. Сторінка DuoFollow отримує стан підключення.

Для порівняння Connector надсилає введене ім’я користувача до Duolingo. З відповідей він використовує ідентифікатори акаунтів, імена користувачів, відображувані імена, посилання на аватари й відомості про підписки. Порівняння відбувається в браузері. Connector передає результати й потрібні для їх відображення відомості про профілі на сторінку DuoFollow. Після підтвердження відписки Connector надсилає Duolingo ідентифікатори акаунта та вибраного профілю, щоб видалити підписку.

Куди передаються дані

DuoFollow не має власного сервера для зберігання акаунтів або результатів. Duolingo отримує HTTPS-запити, потрібні для вибраних дій. Браузер завантажує аватари безпосередньо із серверів зображень за посиланнями з відповідей Duolingo. Ці сервери отримують мережеві дані, зокрема IP-адресу.

Сайт DuoFollow розміщено на GitHub Pages. GitHub реєструє IP-адреси відвідувачів для безпеки. DuoFollow використовує описані дані тільки для роботи своїх функцій. Ми не продаємо ці дані й не використовуємо їх для реклами або рішень щодо кредитоспроможності. Ми дотримуємося правил Chrome Web Store щодо даних користувачів, включно з вимогами Limited Use.

Зберігання та керування доступом

Connector зберігає згоду в локальному сховищі розширення. Сайт зберігає в браузері мову, тему й ім’я акаунта з останнього успішного порівняння. Під час наступного відвідування за наявності доступу DuoFollow може повторити порівняння. Результати зберігаються в пам’яті сторінки, а зображення можуть залишатися в кеші браузера.

Щоб припинити доступ, відкрий DuoFollow Connector і натисни «Відключити доступ». Розширення відкликає дозволи, а сайт очищує результати й збережене ім’я, коли виявляє зміну. Доступ також можна відкликати в налаштуваннях Chrome. Щоб видалити мову, тему й збережене ім’я, очисть дані сайту DuoFollow у Chrome. Уже виконані зміни підписок зберігаються в Duolingo.
