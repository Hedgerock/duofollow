Політика конфіденційності

Оновлено 15 листопада 2026 року

Політика поширюється на вебсайт DuoFollow і розширення DuoFollow Connector для Chrome. DuoFollow — незалежний проєкт, який підтримує Dmitro Vasyliev.

Дані для роботи з Duolingo

Після надання доступу в налаштуваннях Connector розширення читає файл cookie сеансу на www.duolingo.com, щоб визначити активний акаунт і перевірити вхід. Значення cookie використовується в розширенні та браузером для автентифікованих запитів до Duolingo. Сторінка DuoFollow отримує стан підключення.

Для порівняння Connector надсилає введене ім’я користувача до Duolingo. З відповідей він використовує ідентифікатори акаунтів, імена користувачів, відображувані імена, посилання на аватари й відомості про підписки. Порівняння відбувається в браузері. Connector передає результати й потрібні для їх відображення відомості про профілі на сторінку DuoFollow. Після підтвердження у вікні Connector розширення надсилає Duolingo ідентифікатори акаунта та вибраного профілю, щоб видалити підписку. У разі втрати відповіді Connector може повторно прочитати список підписок для перевірки результату.

Куди передаються дані

DuoFollow не має власного сервера для зберігання акаунтів або результатів. Duolingo отримує HTTPS-запити, потрібні для вибраних дій. Браузер завантажує аватари безпосередньо з дозволених серверів зображень за посиланнями з відповідей Duolingo. Ці сервери отримують мережеві дані, зокрема IP-адресу.

Сайт DuoFollow розміщено на GitHub Pages. GitHub реєструє IP-адреси відвідувачів для безпеки. DuoFollow використовує описані дані тільки для роботи своїх функцій. Дані не продаються й не використовуються для реклами або рішень щодо кредитоспроможності. Обробка даних відповідає правилам Chrome Web Store щодо даних користувачів, включно з вимогами Limited Use.

Зберігання та керування доступом

Connector зберігає згоду в локальному сховищі розширення. Сайт зберігає в браузері мову, тему, налаштування оформлення й ім’я акаунта з останнього успішного порівняння. Під час наступного відвідування за наявності доступу DuoFollow може повторити порівняння. Результати зберігаються в пам’яті сторінки, а зображення можуть залишатися в кеші браузера.

Сховище сесії Chrome містить останню підтверджену спробу відписки для перевірки результату після перезапуску фонового процесу. Запис містить ідентифікатори акаунта та вибраного профілю й унікальне для запиту незворотне контрольне значення для звірки сесії. Після обробки ці дані замінюються результатом. Сховище сесії очищується після перезапуску браузера.

Кнопка «Відключити доступ» у DuoFollow Connector відкликає дозволи. Сайт очищує результати й збережене ім’я, коли виявляє зміну. Доступ також можна відкликати в налаштуваннях Chrome. Очищення даних сайту DuoFollow у Chrome видаляє мову, тему, налаштування оформлення й збережене ім’я. Уже виконані зміни підписок зберігаються в Duolingo.
