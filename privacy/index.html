Privacy Policy

Last updated on November 15, 2026

This policy covers the DuoFollow website and the DuoFollow Connector extension for Chrome. DuoFollow is an independent project maintained by Dmitro Vasyliev.

Data used for Duolingo features

After access is granted in the Connector settings, the extension reads the Duolingo session cookie on www.duolingo.com to identify the signed-in account and check the session. The cookie is used inside the extension and by the browser for authenticated requests to Duolingo. The DuoFollow page receives the connection status and, when the session is verified, the active account ID, username and avatar URL if available.

The Connector requests the active profile by its ID and compares its follows when the DuoFollow home page opens with access granted. If a username is entered manually, the Connector sends that username to Duolingo to verify the profile. It uses account IDs, usernames, display names, avatar URLs and follow relationships from the responses. The Connector compares the lists in the browser and sends the results and relevant profile details to the DuoFollow page. After the unfollow is confirmed, the extension sends the account ID and selected profile ID to Duolingo to remove that follow. If the response is lost, the Connector can read the follows again to check the result.

Where the data goes

DuoFollow has no developer-operated account or results database. Duolingo receives the HTTPS requests needed for the selected features. The browser loads avatars directly from approved image hosts using links in the Duolingo responses. Those hosts receive connection information such as the visitor’s IP address.

The DuoFollow site is hosted on GitHub Pages. GitHub logs visitor IP addresses for security. DuoFollow uses the data described here only to provide its features and does not use it for advertising, sale or credit decisions. DuoFollow handles user data in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Storage and access controls

The Connector saves consent and the extension language in its local Chrome storage. The website saves the language, theme, appearance preferences and the username of a successful manual comparison in the browser. That username can be used again on a subsequent visit with access available. The automatically detected profile and comparison results are held in memory. The browser may cache avatar images.

Chrome session storage holds the latest confirmed unfollow attempt so the Connector can check the result after its background worker restarts. It holds the account and target profile IDs and a one-way, request-specific digest for matching the Duolingo session. Once the outcome has been processed, the stored result replaces that data. Session storage is cleared when the browser restarts.

“Disconnect” in the DuoFollow Connector settings revokes the extension’s Duolingo permissions. The site clears the comparison and remembered username when it detects the change. Chrome also provides controls to revoke site access. Clearing DuoFollow site data in Chrome removes the language, theme, appearance preferences and saved username. Changes already made to follows remain in Duolingo.

Quick unfollow terms

Quick unfollow is optional and off by default. When enabled in the extension settings, selecting Unfollow in the DuoFollow website dialog confirms removal of the selected follow without opening an extension window.

The extension stores the setting locally. The DuoFollow site reads its on or off status to select the confirmation flow. Turning the setting off in the extension settings restores additional confirmation in the extension.
